# Triage labels

The engineering skills use five canonical triage roles. This repository uses
the default string for every role.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must evaluate the issue. |
| `needs-info` | `needs-info` | Work is waiting on the reporter. |
| `ready-for-agent` | `ready-for-agent` | The issue is specified enough for an AFK agent. |
| `ready-for-human` | `ready-for-human` | The issue requires human implementation. |
| `wontfix` | `wontfix` | The issue will not be actioned. |

When a skill names a triage role, apply the corresponding GitHub label from
this table. Edit the mapping here if the repository's label vocabulary changes.
